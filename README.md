# Login-Portal
Project Description
This is a Java-based authentication tool that simulates a secure student login portal. It validates user credentials against stored data to grant access. This project was developed as part of my Bachelor of Science in Computer Science studies to practice security logic and input validation.

Core Features
Credential Matching: Uses Boolean logic to verify both username and password.
User Feedback: Provides clear system messages for both successful and failed login attempts.
Input Validation: Correctly handles terminal-based string comparisons for user identification.
Technical Skills UsedJava Programming: Developed using standard Java syntax and logical structures.
String Comparison: Utilizing the .equals() method for accurate data validation.
Scanner Implementation: Managing dynamic user input through the console.
Conditional Logic: Implementing if-else structures to handle system outcomes.
